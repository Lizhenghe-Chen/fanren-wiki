## 二、换算模型口径（主观设定，非科学结论）

页面为趣味创作，以下均为**主观设计**，不构成任何评价或建议。

### 1. 维度与权重（DIMS）

自身 8 维权重合计 1.00；「家庭出身」单独处理（w=0，非对称加成）：

| key | 名称 | 权重 |
|---|---|---|
| edu | 学历 | 0.10 |
| job | 职业 | 0.10 |
| pos | 职位 | 0.19 |
| pwealth | 个人净资产（己力） | 0.16 |
| family | 家庭出身（家底） | 0（单独加成） |
| income | 收入 | 0.11 |
| net | 人脉 | 0.13 |
| health | 健康 | 0.09 |
| fame | 影响力 | 0.12 |

### 2. 计算模型（长板主导）

- 自身 8 维线性加权 `Ws`；
- 取自身最高 3 维做几何平均 `Ts = (v0·v1·v2)^(1/3)`（对短板敏感，偏科天才不被平均分拖累）；
- `ss = Ts × 0.76 + Ws × 0.24`；
- 家庭出身非对称加成：`S = ss + (family − ss) × 0.12`（仅当 family > ss 时生效；自身修为超过出身不惩罚）。
