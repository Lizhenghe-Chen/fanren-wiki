### 2. 算法

```text
Ws = 参与项的 Σ(分值×系数) / 参与项的 Σ系数（不含家庭支持）
Ts = 除家庭支持、身体状态外，最高三项分值的几何平均
ss = Ts × 0.76 + Ws × 0.24
S  = ss + max(家庭支持分值 − ss, 0) × 0.12
```

76%、24%、12%、所有分档及境界门槛均为游戏设计，不是权威统计推导出的科学参数。最高三项几何平均只对这三项内部的不均衡敏感，不表示全维度的短板惩罚。

### 4. 稀有度与雷达图


雷达图半径 = 实际分值 / 5；悬浮单项境界使用同一境界函数。学识最高 4.9 对应半径 98%，职业最高 2.0 为 40%，健康最高 5.0 为 100%。这不是完成度图，不应仅为“看起来满格”而拉伸各轴；不参与健康时该轴标注未参与、数据点留空。

健康最高／最低档相差 4.7；其他项不变时，身体状态计分造成的自身综合分差为 `4.7×0.12/1.04×0.24≈0.13015`，家庭支持加成可能缩小这个差值。不参与仍会改变分母，但最高健康 5 分高于其余计分项的最大可能均值，因此相较不参与不会降低结果。较低状态可能低于不参与时的结果，这是可选维度的现行规则，不等于所有状态都获加分。
