## 二、换算模型口径（主观设定，非科学结论）

页面为趣味创作，以下均为**主观设计**，不构成任何评价或建议。

### 1. 维度与权重（DIMS）

自身 9 维权重合计 1.00；「家庭出身」单独处理（w=0，非对称加成）：

| key | 名称 | 权重 |
|---|---|---|
| edu | 学识 / 学历（灵根·悟性） | 0.08 |
| shen | 神识 / 见识（认知储备） | 0.10 |
| job | 职业领域（功法） | 0.09 |
| pos | 职位 / 职级（境界） | 0.18 |
| pwealth | 个人净资产（己力·资源） | 0.15 |
| family | 家庭出身（家底·助力） | 0（单独加成） |
| income | 个人税前年收入（俸禄） | 0.10 |
| net | 人脉 / 圈层（道统） | 0.12 |
| health | 健康 / 精力（道基） | 0.08 |
| fame | 影响力 / 成就（道果） | 0.10 |

### 2. 计算模型（长板主导）

- 自身 9 维线性加权 `Ws`；
- 取自身最高 3 维做几何平均 `Ts = (v0·v1·v2)^(1/3)`（对短板敏感，偏科天才不被平均分拖累）；
- `ss = Ts × 0.76 + Ws × 0.24`；
- 家庭出身非对称加成：`S = ss + (family − ss) × 0.12`（仅当 family > ss 时生效；自身修为超过出身不惩罚）。
